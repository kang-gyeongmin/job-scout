# 지원자 프로필

- 목표 직무: 데이터 엔지니어 / AI 개발·엔지니어 (신입~주니어, 3년 이하)
- 희망 지역: 서울·경기·인천 (수도권)
- 거주지: 인천 서구 (인천서구청·심곡동 인근)

## 기술 스택
- Python, SQL — 데이터 처리·파이프라인 작성
- Spark, Airflow, Kafka — 분산 처리, 워크플로 오케스트레이션, 스트리밍
- AWS(EC2, S3), Docker — 클라우드 인프라·컨테이너 환경 경험
- LLM/AI 활용 — LLM API, 에이전트 개발 경험 (본 프로젝트 포함)

## 선호 / 채점 기준 (아래 조건을 종합해 점수를 조정할 것)
- **직무**: 데이터 엔지니어 또는 AI 개발/엔지니어 직무를 가장 높게. 데이터 파이프라인
  구축·운영, 대규모 데이터 환경이면 가점. 직무가 벗어나면 크게 감점.
- **직원수**: 약 100명 이상 규모를 우대. 공고·회사정보에 직원수가 나오고 100명 미만이면
  감점(정보가 없으면 중립).
- **급여**: 월급 300만원(연 3,600만원 안팎) 이상이 명시되면 가점. "회사내규에 따름" 등
  미공개는 중립(감점하지 않음).
- **점심 제공**: 대기업이 아니라면 중식(점심) 제공 여부를 중요하게 볼 것 — 대기업이 아닌데
  식대·중식 제공 언급이 없으면 감점, 있으면 가점. (대기업이면 이 조건은 신경 쓰지 않음)
- **통근/기숙사**: 기숙사(사택) 제공이면 위치는 신경 쓰지 않음. 기숙사가 아니라면
  거주지(인천 서구)에서 대중교통 **편도 1시간 이내** 위치를 우대:
  - 가까움(가점): 인천 전역, 부천, 김포, 서울 서부(강서·마곡·구로·영등포·여의도 등)
  - 멂(감점): 판교·분당·강남·동탄·수원 남부 등 편도 1시간을 크게 넘는 곳
- IT 직무(데이터·개발) 인턴/일경험도 관심 — 수도권이거나 지역무관이면 정규직이 아니어도
  위 기준을 만족하는 선에서 긍정적으로 채점. 단 비IT 직무(마케팅·기획·영업 등)는 제외.
